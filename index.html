GeoForma 隐私政策

生效及更新日期：2026 年 10 月 26 日适用版本：GeoForma 1.0.0开发者：Viktor Xu（GitHub：radiofor）

GeoForma 是一款在 Windows 上运行的地理影像标注工具。本政策说明软件如何处理您选择的文件、在本地生成的数据，以及资源下载和反馈过程中涉及的信息。

1. 本地文件与模型推理

GeoForma 根据您的操作读取影像、参考影像、VRT、YAML 清单、项目和模型资源，用于影像显示、提示交互、模型推理、轮廓编辑与标签导出。

影像与标签可能包含地理位置、空间范围或其他敏感内容；项目文件也可能包含文件路径、标注、提示点、模型配置及工作状态。这些内容在您的设备上处理。GeoForma 不会自动将导入的影像、标签、项目或特征缓存上传给开发者，也不通过云端推理服务处理这些内容。

GeoForma 自身不要求您注册或登录应用账户。本地标注功能不包含广告、用户行为统计或自动远程崩溃上报。

2. 本地保存、缓存与日志

您保存的项目和导出结果写入您选择的位置。软件还会在本机保存模型偏好、恢复记录、下载资源、特征与候选缓存，以及用于排查故障的日志。

缓存可能包含由影像生成的派生数据；恢复记录与日志可能包含文件路径、模型或设备信息、处理状态及异常信息。这些文件默认保留在本机，不会自动发送给开发者。

普通安装版默认数据目录为 %LOCALAPPDATA%/GeoForma；商店安装方式或自定义配置可能影响实际位置。您可在“设置 → 资源配置 → 更多 → 打开资源文件夹”查看资源目录。

3. 联网与第三方资源

在配置或加载所需资源时，GeoForma 可以从 PyTorch、Meta 等提供方及其分发服务下载运行库或模型权重。下载连接采用 HTTPS，资源配置会核对清单中的文件大小及 SHA256。您也可以直接导入已有本地文件。

资源提供方会收到完成连接所需的 IP 地址、请求的资源路径、客户端请求标识和下载续传范围等网络信息；其日志记录和保存方式由相应服务提供方决定。GeoForma 不会把您的影像、标签、项目或特征缓存附加到这些下载请求。

用户主动打开官方网站或其他外部链接时，将由浏览器访问相应服务。文件引用、共享路径或其他外部数据源的访问也取决于您选择的数据及其来源；本政策不代表这些第三方服务的隐私规则。使用本地数据且所需运行库、权重均已配置后，模型推理可在本地离线进行。

4. 隐私政策网页与反馈

本政策网页通过 GitHub Pages 托管。网页自身没有添加统计脚本、广告、第三方字体或追踪代码；GitHub 作为托管提供方仍可能处理访问网页所需的 IP 地址及访问日志等信息，详见 GitHub 隐私声明。

您可以通过 geoforma-privacy 仓库的 Issues联系开发者。提交反馈时，GitHub 会处理您的账号信息和您主动提供的内容，开发者也会看到这些内容，并可用于处理您提出的问题。

Issues 是公开页面。请勿公开提交个人信息、密码、完整用户目录、敏感影像或未经脱敏的项目与日志。如需私下沟通，可先仅提出获取私下联系方式的请求。

5. 您对数据的管理

您可以决定导入哪些文件、保存或导出哪些结果，并自行备份、迁移或删除本地数据。软件提供下载缓存清理选项；清理下载缓存不等于删除已经配置的运行库、模型权重或用户项目。

卸载软件通常会保留原始影像、项目、恢复记录和自行下载的模型资源；是否清理特征和候选缓存取决于卸载选项。删除本地文件前，请确认已备份需要保留的工作。

6. 第三方平台与安全

Microsoft Store 的安装、账户、更新及平台诊断由 Microsoft 的服务和系统设置管理，适用 Microsoft 的相关隐私规则。GitHub、资源下载服务及您主动访问的网站也分别适用其隐私规则。

GeoForma 对资源下载使用 HTTPS 和清单校验，但本政策不承诺所有本地文件均已加密，也不保证设备或第三方服务绝对安全。请妥善管理设备访问权限及备份。

7. 政策更新

如果软件的数据处理方式发生变化，开发者会更新本政策并修改页面日期。更新内容会在本页面及仓库中提供。
