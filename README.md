# GeoForma 隐私政策

GeoForma 是一款面向地理影像的桌面标注工具，支持影像与参考数据导入、交互式模型分割、轮廓编辑与平滑、类别管理、项目保存恢复及矢量标签导出。

本仓库用于托管 GeoForma 的隐私政策，说明应用在本地文件处理、模型推理、数据保存与缓存、运行库和模型权重下载及用户反馈等过程中如何处理数据。

隐私政策正文见 [PRIVACY.md](PRIVACY.md)；网页版本由本仓库的 [index.html](index.html) 提供，通过 GitHub Pages 发布至 [GeoForma 隐私政策网页](https://radiofor.github.io/geoforma-privacy/)。修改政策时，请同步更新两个文件的内容、适用版本和日期。

如需反馈隐私相关问题，可通过本仓库的 [Issues](https://github.com/radiofor/geoforma-privacy/issues) 联系开发者。请勿在公开反馈中提交个人信息、密码或未经脱敏的数据文件；需要私下沟通时，可先仅请求私下联系方式。
